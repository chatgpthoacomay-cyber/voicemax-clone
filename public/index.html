2 Chạy

Bấm Bắt đầu để hệ thống chạy tuần tự từng file (an toàn nhất, hầu như không dính rate-limit OpenAI).

Vì sao chỉ chạy 1 luồng?

OpenAI giới hạn số token/phút (TPM) trên mỗi API key. Chạy tuần tự 1 file là ổn định nhất — không bị cắt cụt đoạn hay chờ dài.

Nếu vẫn bị limit, hệ thống tự chờ rồi tiếp tục từ lệnh đã lưu — không mất tiến độ (tối đa 5 lần tự chờ liên tiếp mỗi file).
